# KORG ELECTRIBE MX — EMX-1 (HLE-эмулятор в одном файле)

Полностью рабочая веб-эмуляция грувбокса Korg Electribe EMX-1: пиксельная панель на чистом CSS/SVG,
нативный аудио-движок (Tone.js + резервный WebAudio) и парсер оригинального дампа карты `.BIN` / `.EMX`.

Всё приложение — один файл [`index.html`](index.html). Без сборки, без зависимостей кроме CDN Tone.js.

## Запуск

Открыть `index.html` в браузере (локально двойным кликом или с любого статического хостинга).
Для iPad: Safari → «Поделиться» → «На экран Домой» — приложение запустится без адресной строки.

## Интерфейс

Панель нарисована в дизайн-пространстве 1600×1168 и автоматически масштабируется под экран
(на iPad 5 landscape 1024×768 коэффициент ≈ 0.61). Вся графика — CSS-градиенты, `box-shadow`
и inline-SVG, внешних картинок нет.

Работающие элементы:

| Элемент | Действие |
|---|---|
| **MASTER VOLUME / TUBE GAIN** | громкость и степень Tube Saturation (`Tone.Distortion`) |
| **DRIVE** (SYNTH FILTER) | дополнительный драйв сатурации |
| **CUTOFF / RESONANCE** (SYNTH FILTER) | `frequency` и `Q` фильтра басовой партии (lowpass 12 dB/oct) |
| **EG TIME** | release огибающей баса |
| **FILTER TYPE** LPF/BPF/HPF | тип фильтра |
| **DRUM PART 1/2/3** | выбор дорожек KICK / SNARE / HI-HAT + прослушивание |
| **SYNTH PART 1** | дорожка SYNTH BASS |
| **1–16** | программирование шагов выбранной дорожки (красный — нота, белый контур — бегущий шаг) |
| **PLAY / STOP / REC** | транспорт, запись-индикатор |
| **TAP TEMPO** | тап-темп (защита от двойных нажатий) |
| **PART MUTE / SOLO** | мьют и соло текущей дорожки |
| **ERASE** | очистка дорожки |
| Вертикальный фейдер (ARPEGGIATOR) | TEMPO 60–200 BPM |
| Ribbon (белая полоса) | играет бас по пентатонике от высоты касания |
| SYNTH PART 2–5 | бас-ноты D#2 / F2 / G2 / A#2 |
| Эффект-блок, PART COMMON, MODULATION | ручки вращаются, кнопки переключаются |
| **◄ ►** | переключение паттернов |

Ручки управляются `pointerdown/pointermove` (мышь и мультитач, каждая ручка — независимый указатель),
диапазон поворота −140°…+140°. Клавиатура на десктопе: `Space` — play/stop, `←/→` — паттерны, `1–4` — дорожки.

## Аудио

* `Tone.js 14.8.49` с CDN Cloudflare (cdnjs), контекст создаётся по первому касанию с
  `latencyHint: 'interactive'` и `lookAhead: 0.02`.
* Цепочка: партии → `Tone.Distortion` (Tube Saturation) → `Tone.Limiter` → выход.
* KICK — `Tone.MembraneSynth`, SNARE — `Tone.NoiseSynth` (decay 0.08), HI-HAT — `Tone.MetalSynth`,
  SYNTH BASS — `Tone.MonoSynth` (sawtooth) → `Tone.Filter` (lowpass, −12 dB/oct).
* Секвенсор — `Tone.Transport.scheduleRepeat('16n')`, визуализация через `Tone.Draw` (без рассинхрона).
* Если CDN недоступен, автоматически включается компактный резервный WebAudio-движок
  (тот же API, lookahead-планировщик 25 мс) — панель остаётся играбельной офлайн.

## Формат дампа

Дамп карты — 1 831 424 байта; паттерны идут блоками по **9984** байта, `offset = index * 9984`
(при выборе паттерна из списка пересчитывается без перезагрузки файла):

| Смещение в блоке | Поле | Обработка |
|---|---|---|
| `+0x0000` | BPM, `Uint16` little-endian | `/10` → `Tone.Transport.bpm` и LCD |
| `+0x0040` | KICK, 16 байт | `> 0` → шаг включён, клавиша светится |
| `+0x0050` | SNARE, 16 байт | то же |
| `+0x0060` | HI-HAT, 16 байт | то же |
| `+0x0070` | SYNTH BASS, 16 байт | то же |
| `+0x011A` | Cutoff `0–127` | `/127` → ручка CUTOFF + фильтр |
| `+0x011B` | Resonance `0–127` | `/127` → ручка RESONANCE + `Q` |

Файл читается `FileReader.readAsArrayBuffer`; поддерживается drag & drop на окно.
Если блок пустой/нечитаемый, включается демо-паттерн (A.01 «SpaceJox» повторяет фотографию панели).

## Производительность

Никаких blur-анимаций и `backdrop-filter` в основном слое, свечение ламп — на `opacity/transform`,
шаги и ручки меняют только классы и CSS-переменные, обновление индикатора шага — через `requestAnimationFrame`.
Расчётная нагрузка — единицы процентов кадра на Apple A9.
